# Frontend rules

- Reuse the shared API client, query hooks, state stores, primitives, and design tokens.
- Keep backend types, routes, loading/error/empty states, English/Arabic copy, RTL, accessibility, and responsive behavior aligned.
- Never hardcode production hosts or expose credentials in browser code.
- Validate changes with lint, TypeScript, focused tests, build, and relevant Playwright coverage.
