# Stratum Frontend Guide

Follow the root project guide and `.claude/rules/frontend.md`. Checkout or subscription UI must also follow `.claude/rules/paddle-billing.md`.

This directory is the React/Vite client. Reuse shared clients, query hooks, stores, primitives, and theme tokens. Keep types, loading/error/empty states, bilingual copy, RTL, accessibility, and responsive behavior aligned.

Run lint, TypeScript, focused tests, build, and relevant Playwright checks before handoff.
